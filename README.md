# Schön Autos — proyecto independiente

Repositorio exclusivo para las demostraciones web de **Schön Autos**, separado del proyecto **Cartas Digitales Interactivas (CDI)**.

## Demostraciones

- [Comparador de diseños](index.html) — permite alternar entre dos propuestas.
- [Propuesta editorial / taller](editorial/index.html).
- [Propuesta tecnológica / IA](ia/index.html).
- [Recursos estáticos](assets/) — estilos, JavaScript y fotografías.

Los archivos de las demos se conservarán a partir de los originales de CDI (PR [#95](https://github.com/fernandoanjp-dotcom/con-acento-carta/pull/95), rama `deploy/schon-autos-commercial-20261106`). La instantánea fuente y el generador original están en `demos/schon-autos/`, procedentes de `demo/schon-autos-20261106`.

## Uso y seguridad

Webs **de demostración**, no producción. Los formularios eran prototipos y no hacen envíos automáticos. Se conserva `noindex,nofollow` y `robots.txt`; no constituyen una medida de acceso privado.

Este repositorio **no contiene ni despliega** la aplicación CDI. No se han trasladado flujos de despliegue automático desde CDI. El archivo histórico del workflow se guarda solo como documentación y no se ejecuta.

## Procedencia

Separación solicitada el 16 de noviembre de 2026 para mantener los trabajos de Schön Autos fuera del desarrollo activo de CDI. El historial anterior permanece consultable en sus referencias originales de GitHub; la migración de archivos no reescribe dicho historial.
